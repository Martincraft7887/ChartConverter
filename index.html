Compatibility notes

The four engines do not share an exact schema. Note types are carried as text names; compatible unknown fields and the original chart are stored in _chartConverter where JSON extensions are supported. Leather preserves per-note characters and multiple strumlines; Codename preserves strumline characters and key counts. Psych Online multikey uses keyCount and combined lane indexes. Standard Psych Engine may ignore that extra field. V-Slice has one player identity per note, so the side is exported as player/opponent and the note type in k; per-note character assignments and engine-specific events may need manual adjustment. Events, BPM changes, metadata, and preferences are carried where an equivalent representation exists.

All processing happens in this browser. Files are never uploaded.
